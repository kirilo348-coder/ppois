# Лабораторная работа №1: множество и многочлен

В проекте реализованы два независимых класса на C++17:

- `Set` — неупорядоченное множество уникальных текстовых атомов и вложенных
  множеств.
- `Polynomial` — многочлен с вещественными коэффициентами, хранящимися в
  порядке возрастания степеней.

## Формат записи множества

Используются фигурные скобки, запятые и непустые атомы. Поддерживаются
вложенные множества:

```text
{a, b, {a, c}, {}}
```

Атомы могут содержать пробелы, но не фигурные скобки и запятые.

## Формат записи многочлена

Коэффициенты вводятся, начиная со свободного члена. Например, `[1, 2, 3]`
соответствует многочлену `1 + 2x + 3x^2`. Значение можно получить через
`evaluate(x)` или вызов объекта `polynomial(x)`. Операция деления возвращает
частное, а метод `divideWithRemainder` также возвращает остаток. Деление на
нулевой многочлен приводит к `std::domain_error`.

## Сборка и запуск

Установите CMake, Git, GNU Make и компилятор C++17. В MSYS2 UCRT64 эти
инструменты можно установить из терминала UCRT64:

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-make mingw-w64-ucrt-x86_64-git mingw-w64-ucrt-x86_64-gcovr mingw-w64-ucrt-x86_64-doxygen
```

Из папки `lab1` настройте сборку, соберите проект и запустите тесты:

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
ctest --test-dir build --output-on-failure
gcovr --root . --filter 'src/(set|polynomial)\.cpp' --fail-under-line 90
.\build\lab1_cli.exe
```

При первой настройке Catch2 для модульных тестов загружается из интернета.
Чтобы собрать только приложение без загрузки тестовых зависимостей, укажите
`-DBUILD_TESTING=OFF`.

Если Git в PowerShell сообщает об отсутствующем или недействительном файле
сертификатов при загрузке Catch2, укажите путь к файлу сертификатов MSYS2
перед настройкой сборки:

```powershell
$env:GIT_SSL_CAINFO = "D:\msys\usr\ssl\certs\ca-bundle.crt"
```

Если MSYS2 установлен в другом месте, замените `D:\msys` на путь к его папке.

Чтобы сгенерировать документацию API с помощью Doxygen, выполните из этой папки:

```powershell
doxygen Doxyfile
```

Сгенерированная HTML-документация появится в `docs/html`.
Отчёт покрытия проверяет реализацию классов `Set` и `Polynomial`; код CLI в
`src/main.cpp` в это измерение не входит.
